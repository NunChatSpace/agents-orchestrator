# Tasks

This directory contains task completion records.

## Convention

A task file is created when a plan phase is fully implemented.

**Filename format:** `{phase_id}_{short-slug}.md`

Example: `phase01_project-bootstrap.md`

## Task File Structure

```md
# Task: {Phase Name}

## Phase
phase01

## Status
done

## Completed At
YYYY-MM-DD

## Files Created / Modified
- path/to/file.go
- path/to/file.ts

## Notes
Any deviations from the plan, assumptions made, or things to know.
```
